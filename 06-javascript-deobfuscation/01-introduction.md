# Módulo 06 — JavaScript Deobfuscation

## Sección 1/11: Introduction

> [!NOTE]
> La deofuscación de código es una habilidad clave para análisis de código y reverse engineering. En ejercicios red/blue team es común encontrar código ofuscado que oculta funcionalidad — por ejemplo malware que usa JavaScript ofuscado para descargar su payload principal. Sin entender qué hace ese código, no se puede completar el análisis ni responder adecuadamente al incidente.

## 📌 Temas que cubre el módulo

- Localizar código JavaScript (dentro de una página HTML)
- Introducción a la ofuscación de código
- Cómo deofuscar código JavaScript
- Cómo decodificar mensajes codificados
- Análisis básico de código
- Envío de requests HTTP básicos

> [!TIP]
> El recorrido es progresivo: primero entender la estructura general de una página HTML para ubicar dónde vive el JS, luego entender qué es la ofuscación y cómo se aplica, después aprender a revertirla, y finalmente analizar manualmente el código ya deofuscado para replicar su funcionalidad y entender qué hace.
