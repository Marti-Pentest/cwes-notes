# Módulo 06 — JavaScript Deobfuscation

## Sección 11/11: Summary

> [!NOTE]
> Cierre del módulo. Repaso del recorrido completo: ubicar JS en el código fuente HTML → entender cómo se ofusca código → beautify + deofuscar código minificado/ofuscado → analizar la lógica deofuscada → replicar requests HTTP manualmente → decodificar strings codificados (Base64/Hex/ROT13) para completar el flujo de análisis end-to-end.

## 📌 Recorrido del módulo

1. Localización del código JS dentro del HTML fuente
2. Formas de ofuscar JavaScript (minificación, packing, ofuscación avanzada)
3. Beautify + deofuscación de código minificado/ofuscado
4. Análisis funcional del código ya deofuscado
5. Replicación manual de requests HTTP (curl) basada en el análisis
6. Encoding/decoding de strings (Base64, Hex, ROT13)
